An `rc-adaptive-menu` action marked with the boolean `data-rc-action-show-label`
keeps its `[data-rc-menu-label]` text visible while promoted, in a theme that
otherwise shows promoted actions with an icon as icon-only, such as
`rc-theme-material`. Use it for a pane's primary action on a wide screen. The
marker has no effect once the action moves to the overflow menu.
