Add `@rcarls/rc-theme-tailwind`, a CSS-only Tailwind CSS v4 token bridge and
calm SaaS reference theme. It maps Tailwind color, typography, spacing,
radius, shadow, and easing variables to the public `--rc-*` semantic contract,
with optional native controls and CSS-only component recipes.
