Adds generated Vue and Svelte typings. `@rcarls/rc-webcomponents/vue` declares
every element in Vue's `GlobalComponents`, and
`@rcarls/rc-webcomponents/svelte` adds them to `svelte/elements`, so `vue-tsc`,
`svelte-check`, and the editor tooling check properties, attribute values, and
typed event details. The docs gain Vue and Svelte guides.
