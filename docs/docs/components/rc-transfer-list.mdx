# rc-transfer-list

Transfer list that enhances a native `<select multiple>` into available and selected panes.

The component renders two listboxes and transfer/reorder actions in between.
Available options are on the left, and selected options appear on the right. It
is an older enterprise/admin UI pattern, but solves the specific problem of
multiple selection within a large amount of options.

Modern use cases include user and permissions management tasks, multi-select for
columns / fields / filters and list re-ordering.

Use `compact` when the surrounding layout should stack the available list,
actions, and selected list in one column. The component does not switch layout
automatically at viewport breakpoints.

## Usage

Wrap a native `<select multiple>`. Its selected options form the selected list, in order, so form
submission sends the values shown there.

```html
<rc-transfer-list available-label="Available planets" selected-label="Mission route">
  <select name="planets" multiple>
    <option value="mercury">Mercury</option>
    <option value="venus" selected>Venus</option>
    <option value="earth">Earth</option>
  </select>
</rc-transfer-list>
```

## Accessibility

Each side is an [`rc-listbox`](./rc-listbox.mdx#accessibility), named by `available-label` and
`selected-label`, with its own list navigation and selection. The action buttons are native
buttons in an [`rc-toolbar`](./rc-toolbar.mdx#accessibility), so arrow keys move between them.
These shortcuts also work while focus is in either list:

| Key                          | Action                                                          |
| ---------------------------- | --------------------------------------------------------------- |
| Alt+Right Arrow              | Adds the highlighted available options.                         |
| Alt+Left Arrow               | Removes the highlighted selected options.                       |
| Alt+Up Arrow, Alt+Down Arrow | Moves the highlighted selected options up or down.              |
| Enter                        | In a single-select available list, adds the highlighted option. |
| Delete                       | In the selected list, removes the highlighted options.          |

Alt+Left and Alt+Right swap in right-to-left text, where the lists swap sides.
