# rc-toolbar

Toolbar that groups consumer-supplied controls into one tab stop with arrow-key navigation, following the [WAI-ARIA Toolbar pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/).

## Usage

Place buttons, toggles, selects, or other focusable controls as direct children, and name the
toolbar with `label`. Elements that cannot take focus, such as separators, render but are
skipped during keyboard navigation.

```html
<rc-toolbar label="Formatting">
  <button type="button">Bold</button>
  <button type="button">Italic</button>
  <hr aria-hidden="true" />
  <button type="button">Align left</button>
  <button type="button">Align right</button>
</rc-toolbar>
```

Direct `rc-button` and `rc-chip` children participate through their native child
buttons, so themed controls keep the toolbar's single roving tab stop. Icon-only
buttons should use `data-rc-button-icon` inside the native button so button and
theme geometry remain synchronized.

## Accessibility

The toolbar has `role="toolbar"`, `aria-orientation`, and an `aria-label` from `label`. It is a
single tab stop: one item has `tabindex="0"` and the rest `tabindex="-1"`, and the toolbar
remembers the last focused item.

| Key                                             | Action                               |
| ----------------------------------------------- | ------------------------------------ |
| Right Arrow (horizontal), Down Arrow (vertical) | Focuses the next item, wrapping.     |
| Left Arrow (horizontal), Up Arrow (vertical)    | Focuses the previous item, wrapping. |
| Home, End                                       | Focuses the first or last item.      |
| Tab                                             | Leaves the toolbar.                  |

Left and Right swap in right-to-left text. See the
[WAI-ARIA Toolbar pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/).
