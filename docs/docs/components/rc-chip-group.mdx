# rc-chip-group

## Usage

Keep fieldset, legend, form value, and selection semantics native:

```html
<fieldset>
  <legend>Recipe scope</legend>
  <rc-chip-group kind="filter" selection="single">
    <rc-chip>
      <label><input type="radio" name="scope" value="all" checked />All</label>
    </rc-chip>
    <rc-chip>
      <label><input type="radio" name="scope" value="favorites" />Favorites</label>
    </rc-chip>
  </rc-chip-group>
</fieldset>
```

Use `selection="multiple"` with checkboxes. Use `selection="none"` for
menu-backed filter buttons with `aria-haspopup`; their menu owns the eventual
selection.

## Accessibility

- `kind="filter"` keeps the native radios or checkboxes as the selection controls, so the
  author's fieldset and legend name the group and each input keeps its role, label, and
  checked state.
- `kind="assist"` gives the group `role="toolbar"` and an `aria-label` from `label`. It is a
  single tab stop: arrow keys along the row move between chips, wrapping, and Home and End move
  to the first and last chip. The arrow keys follow the inline direction, so Left and Right
  swap in right-to-left text.
- `kind="generic"` adds no role or keyboard behavior.

The **Show all** and **Show less** action is a native button whose name changes with the
state, and its icon and separator are decorative.

## Adaptive layout

`layout="auto"` is the default. The group first measures its natural wrapped
layout. When the content needs more than `max-rows="2"`, it becomes one
horizontally scrolling row and inserts a leading **Show all** action. Expanded
content returns to natural wrapping and the same action becomes **Show less**.
The action uses the MDI tune icon and a vertical separator to distinguish the
disclosure control from the authored chip collection.

Use `layout="wrap"` to always wrap or `layout="scroll"` to always keep one
horizontal row. The component uses actual rendered rows, so container size,
text scaling, localization, and consumer content all participate in the
decision without device-pixel-ratio special cases.

The scrolling row hides its scrollbar, so a vertical mouse wheel over it scrolls
the row along its inline axis. At either end of the row, the wheel scrolls the
page as usual. Touch, touch-pad, and Shift+wheel scrolling stay native.

## Coordination modes

- `kind="generic"` is layout-only and accepts any direct `HTMLElement`.
- `kind="assist"` exposes a labeled toolbar with one tab stop and horizontal
  arrow/Home/End navigation.
- `kind="filter"` synchronizes native radio/checkbox state to direct
  `rc-chip` children. Put the group inside an author-owned fieldset.

## Localization

Built-in text follows the element's own `lang`, else `<html lang>`. Override it with
`messages`, or register it for every instance under `rc-chip-group`: `label`, `showAll`, `showLess`. See
[Localization](../guide/localization).
