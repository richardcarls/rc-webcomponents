## Markup

```html
<rc-chip variant="filter">
  <button type="button">Vegetarian</button>
</rc-chip>

<rc-chip variant="input" removable>
  <button type="button" aria-label="Remove basil">Basil</button>
  <span slot="remove-icon" class="material-symbols-outlined" aria-hidden="true"> close </span>
</rc-chip>

<rc-chip>
  <a href="/recipes">Recipes</a>
</rc-chip>
```

Button-backed filter chips toggle `selected` on user activation and add
`aria-pressed` only when the author has not supplied stronger toggle semantics.
For form-backed filters, keep the native input inside a direct label:

```html
<rc-chip variant="filter">
  <label><input type="checkbox" name="category" value="quick" />Quick</label>
</rc-chip>
```

For removable chips, the direct native button is the sole removal action and
fires `rc-chip-remove`. The trailing remove icon is presentational, so it does
not add another tab stop or duplicate button semantics.

Without a theme, button and link chips retain their browser appearance.
Packaged themes opt into chip sizing, shape, selection colors, and focus
treatment.

## Groups

Use `rc-chip-group` for adaptive wrapping/scrolling, native filter semantics,
and an optional assist-chip toolbar keyboard model:

```html
<rc-chip-group kind="assist" label="Recipe actions">
  <rc-chip variant="filter">
    <button type="button">Quick</button>
  </rc-chip>
  <rc-chip variant="filter">
    <button type="button">Vegetarian</button>
  </rc-chip>
</rc-chip-group>
```

`rc-toolbar` remains appropriate for mixed control toolbars that do not need
chip-group overflow disclosure.

### Dense, height-constrained fields

A chip's accessible touch target (`--rc-chip-touch-target-block-size`,
`3rem` by default) applies unconditionally, unlike `rc-button`'s
opt-in-via-`icon-only` inflation — reasonable on its own, but a poor fit
inside a field that can't spare that much height, such as a multi-select
value area in `rc-search-bar` or `rc-combobox`. `--rc-chip-touch-target-overlap-block-start`
and `-block-end` (zero by default) let a theme or consumer give that
reserved space back on the block axis, the same pattern as `rc-button`'s
own touch-target overlap tokens but vertical instead of horizontal:

```css
.chip-field rc-chip {
  --rc-chip-touch-target-overlap-block-start: 8px;
  --rc-chip-touch-target-overlap-block-end: 8px;
}
```
