## Usage

Place a native `<textarea>` inside the element. Its content is the initial Markdown, and it keeps
the value for form submission.

```html
<label for="notes">Notes</label>
<rc-markdown-editor>
  <textarea id="notes" name="notes"># Shopping list</textarea>
</rc-markdown-editor>
```

The editor composes its formatting surface from `rc-toolbar`, `rc-button`, and
a native `<select>` for the heading level, allowing the selected theme to style
the controls consistently with the rest of an application.

## Accessibility

The rich editing surface is a `role="textbox"` with `aria-multiline="true"`, named by the native
textarea's labels or `aria-label`; clicking a label focuses the active editing surface. Source mode is
an [`rc-textarea`](./rc-textarea.mdx#accessibility) named by the `source` message. The formatting
toolbar is an [`rc-toolbar`](./rc-toolbar.mdx#accessibility) of native buttons that report active
formats with `aria-pressed`, and the link editor is a labeled `role="dialog"` popover.

A wrapping label names the editor without including the textarea's initial Markdown content.
Label click forwarding stops when the editor disconnects and follows its current labels when
it reconnects.

| Key              | Action                                |
| ---------------- | ------------------------------------- |
| Ctrl/Cmd+B       | Bold                                  |
| Ctrl/Cmd+I       | Italic                                |
| Ctrl/Cmd+U       | Underline                             |
| Ctrl/Cmd+\`      | Inline code                           |
| Ctrl/Cmd+K       | Opens the link editor                 |
| Ctrl/Cmd+Shift+S | Switches between rich and source mode |

## Localization

Built-in text follows the element's own `lang`, else `<html lang>`. Override it with
`messages`, or register it for every instance under `rc-markdown-editor`: `source`, `linkPopover`, `url`, `applyLink`, `openLink`, `removeLink`, `shortcut`; the toolbar reads `rc-editor-toolbar` (`toolbar`, `bold`, `italic`, `underline`, `strikethrough`, `inlineCode`, `link`, `headingLevel`, `paragraph`, `heading`, `blockquote`, `bulletList`, `orderedList`, `codeBlock`, `codeBlockLanguage`, `languagePlaceholder`, `languageHint`, `sourceMode`, `sourceModeHint`, `shortcut`). See
[Localization](../guide/localization).
