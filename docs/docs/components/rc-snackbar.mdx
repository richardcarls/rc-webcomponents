## Usage

```html
<rc-snackbar id="snackbar"></rc-snackbar>
```

```js
document.querySelector('#snackbar').show({
  message: 'Recipe saved',
  actionLabel: 'Undo',
});
```

Snackbars do not move focus. They announce through a polite status live region
and queue messages by default.

The unthemed surface uses system canvas colors and a plain border, while its
action retains native button styling. Packaged themes provide snackbar color,
shape, spacing, and action treatment.
