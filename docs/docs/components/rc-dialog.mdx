# rc-dialog

Draggable, resizable wrapper for a native `<dialog>`, following the [WAI-ARIA Dialog Modal pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).

## Fullscreen variant

Use `variant="fullscreen"` for a surface that follows the current visual viewport, including
browser zoom offsets and software-keyboard resizing. Move and resize behavior is disabled for
this variant. The consumer continues to author the native dialog content and accessible close
action.

```html
<rc-dialog variant="fullscreen">
  <dialog aria-labelledby="picker-title">
    <header>
      <button aria-label="Close">✕</button>
      <h2 id="picker-title">Choose categories</h2>
      <button>Done</button>
    </header>
  </dialog>
</rc-dialog>
```

## Theming

The default demo mode shows the component without a package theme. Use the shared preview controls on this page to compare inherited, light, and dark color schemes or to apply the optional Material theme only inside the demo frames.

Set `--rc-dialog-min-inline-size`, `--rc-dialog-max-inline-size`, and
`--rc-dialog-max-block-size` on `<rc-dialog>` or a theme scope to bound the
standard surface. The Material theme supplies its viewport-clamped 280px to
560px dialog width. `--rc-dialog-scrim` customizes the modal backdrop.
