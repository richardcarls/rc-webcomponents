# Theme previews

Use the theme and color mode controls above demos to preview components in the
different supported themes. Substrate is the lightweight reference theme and is
the default for this showcase. Material remains available for comparison, and
Windows 3.1 is a period theme that is useful for more than nostalgia: it is
square, motionless, hover-free, and light only, so it exercises parts of the
token contract that two modern themes never reach.
