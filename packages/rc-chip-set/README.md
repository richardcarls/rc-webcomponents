# @rcarls/rc-chip-set

Chip set coordinator for arrow-key navigation across chip controls.

```html
<rc-chip-set label="Filters">
  <rc-chip variant="filter"><button type="button">Vegetarian</button></rc-chip>
  <rc-chip variant="filter"><button type="button">Quick</button></rc-chip>
</rc-chip-set>
```

Selection remains owned by each chip or native control.
